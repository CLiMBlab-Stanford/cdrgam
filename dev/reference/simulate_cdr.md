# Simulate irregular streams from fixed impulse-response functions

Creates irregular impulse and response times. Predictor columns are
sample-orthogonal and standardized, and responses are generated by the
additive convolution of the supplied ground-truth IRFs plus Gaussian
noise.

## Usage

``` r
simulate_cdr(
  irfs,
  n_impulses = 500,
  n_responses = 600,
  duration = 60,
  window = 2,
  intercept = 0,
  noise_sd = 1,
  seed = NULL
)
```

## Arguments

- irfs:

  Named non-empty list of functions. One-argument functions define
  linear lag IRFs; two-argument functions of lag and predictor value
  define nonlinear tensor IRFs.

- n_impulses:

  Number of impulses.

- n_responses:

  Number of responses.

- duration:

  Duration of the simulated series.

- window:

  Maximum causal lag included in the convolution.

- intercept:

  Response intercept.

- noise_sd:

  Gaussian response noise standard deviation.

- seed:

  Optional random seed.

## Value

A list containing impulse and response data, IRFs, noiseless components,
and simulation settings.
